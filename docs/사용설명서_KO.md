## 1. 개요

**Bartender Lite**는 컴퓨터에서 직접 라벨(바코드, QR 코드, 제품 정보 등)을 디자인하고 인쇄할 수 있는 무료 애플리케이션입니다. Excel 파일에서 대량 데이터를 가져올 수 있으며, TSC 시리즈와 같은 전용 라벨 프린터나 기타 모든 프린터로 직접 인쇄할 수 있습니다.

**주요 기능:**
- 텍스트, Excel 데이터 필드, 바코드, QR 코드, 도형, 이미지를 자유롭게 배치하여 라벨을 디자인합니다.
- 라벨 크기와 행/열 수를 기반으로 전체 용지 크기를 자동으로 계산합니다.
- Excel 데이터를 기반으로 대량 인쇄(메일 머지)를 수행합니다.
- 직접 인쇄하거나 디자인한 크기와 정확히 일치하는 PDF로 내보낼 수 있습니다.
- 다국어 인터페이스 지원: 베트남어, 영어, 중국어 간체, 한국어, 일본어.

## 2. 화면 구성 개요

애플리케이션 화면은 4개의 주요 영역으로 구성됩니다:

| 영역 | 위치 | 기능 |
|---|---|---|
| **상단 도구모음** | 화면 상단 | 로고, 언어 선택, 템플릿 열기/저장, Excel 데이터 가져오기, 미리보기, 인쇄 범위, 인쇄 매수, 프린터 선택, 인쇄, PDF 내보내기, 전체 삭제 |
| **왼쪽 패널** | 화면 왼쪽 | 디자인 요소 추가, 가져온 Excel 열 목록, 인쇄 설정(라벨 크기, 격자, 용지 크기) |
| **디자인 캔버스** | 화면 중앙 | 라벨 위에 요소를 드래그하여 배치하는 영역 |
| **오른쪽 패널** | 화면 오른쪽 | 현재 선택된 요소의 상세 속성(크기, 위치, 서식 등) |

캔버스 양쪽에 있는 작은 파란색 캡슐 모양 버튼은 왼쪽/오른쪽 패널을 **표시/숨기기** 위한 것으로, 필요할 때 더 넓은 작업 공간을 확보할 수 있습니다.

캔버스 오른쪽 하단에는 캔버스를 확대/축소할 수 있는 **확대/축소** 도구모음과, 화면에 맞게 자동으로 조정하는 "맞춤" 버튼이 있습니다.

## 3. 인터페이스 언어 변경

왼쪽 상단의 로고와 앱 이름 옆에 언어 선택 상자가 있습니다. 클릭하여 다음 중 선택하세요:

- 🇻🇳 Tiếng Việt (베트남어, 기본값)
- en English (영어)
- 🇨🇳 简体中文 (중국어 간체)
- 🇰🇷 한국어
- 🇯🇵 日本語 (일본어)

전체 인터페이스(버튼, 레이블, 메시지)가 즉시 전환됩니다. 선택한 언어는 다음에 앱을 열 때 **자동으로 기억**되므로 다시 선택할 필요가 없습니다.

## 4. 라벨 크기 및 용지 크기 설정

왼쪽 패널 하단의 **"인쇄 설정"** 영역에 있습니다:

### 4.1. 측정 단위
작업 단위를 선택하세요: **밀리미터 (mm)**, **인치 (in)** 또는 **픽셀 (px)**.

### 4.2. 사전 설정 크기
자주 사용되는 라벨 크기(35x22mm, 70x100mm, 80x40mm, 100x50mm, 100x75mm)를 빠르게 선택하거나, **"사용자 지정"**을 선택하여 직접 크기를 입력할 수 있습니다.

### 4.3. 너비 x 높이 (라벨 1개)
**라벨 1개**의 크기를 입력하세요 — 이는 화면 중앙에 있는 디자인 캔버스의 실제 크기입니다.

### 4.4. 격자 (행 x 열)
- **행**: 한 인쇄 페이지에서 세로로 배열되는 라벨 수입니다.
- **열**: 한 인쇄 페이지에서 가로로 배열되는 라벨 수입니다(즉, 사용 중인 용지 롤/시트의 한 줄에 배열된 라벨 수).

> ⚠️ **중요:** 라벨 용지가 한 줄에 3개씩 배열되어 있다면 **열 = 3**으로 입력하세요. 열 수를 잘못 입력하면 라벨이 용지의 잘못된 위치에 인쇄됩니다.

### 4.5. 전체 용지 크기 (너비 x 높이)
이 항목은 (라벨 너비 × 열 수) × (라벨 높이 × 행 수)로 **자동 계산**되며, 직접 입력하거나 수정할 수 없습니다. 이는 인쇄 또는 PDF로 내보낼 때 실제로 사용되는 용지 크기입니다.

**예시:** 35x22mm 라벨이 한 줄에 3개씩 배열된 용지 롤 → 열 = 3, 행 = 1로 입력 → 전체 용지 크기가 자동으로 105 x 22mm로 계산됩니다.

## 5. 디자인 요소 추가 및 편집

**"요소 추가"** 영역(왼쪽 패널 상단)에서 추가하려는 요소 유형을 클릭하세요:

| 요소 | 설명 |
|---|---|
| 🔤 **텍스트** | 직접 입력하는 고정된 내용의 자유 텍스트 |
| 🗄️ **Excel 필드** | 가져온 Excel 파일의 특정 열에서 내용을 자동으로 가져오는 텍스트 상자 |
| \|\|\|\| **바코드** | 다양한 형식을 지원하는 바코드 |
| ▦ **QR 코드** | QR 코드 |
| ▢ **도형** | 장식용 사각형/테두리 |
| 🖼️ **이미지 삽입** | 로고 또는 PNG, JPG, SVG 이미지 삽입 |

### 5.1. 캔버스에서 요소 작업하기
- **이동:** 마우스로 드래그하거나, 요소가 선택된 상태에서 방향키(↑↓←→)를 사용합니다. **Shift** + 방향키를 누르면 더 빠르게 이동합니다(10px 단위).
- **크기 조정:** 선택된 요소의 네 모서리/네 변에 있는 작은 파란색 사각형을 드래그합니다.
- **회전:** 요소 위의 파란색 점을 드래그하거나, 오른쪽 패널의 "회전 (°)" / "사용자 지정 각도" 입력란을 사용합니다.
- **복제:** 요소를 선택한 후 **Ctrl+C**, **Ctrl+V**를 누르거나 오른쪽 패널의 "복제" 버튼을 클릭합니다.
- **요소 하나 삭제:** 선택한 후 오른쪽 패널의 "이 요소 삭제" 버튼을 클릭하거나 **Delete** 키를 누릅니다.
- **전체 디자인 삭제:** 도구모음의 빨간색 **"전체 삭제"** 버튼을 클릭합니다.

> 💡 요소는 항상 디자인 영역(라벨 경계) 밖으로 드래그/이동할 수 없도록 제한됩니다.

### 5.2. 공통 속성 (오른쪽 패널)
요소를 선택하면 오른쪽 패널에 다음이 표시됩니다:
- **페이지 기준 정렬:** 라벨을 기준으로 왼쪽/가운데/오른쪽, 위쪽/가운데/아래쪽 정렬.
- **크기 및 위치 (px):** 너비, 높이, X 좌표, Y 좌표, 회전 각도.

### 5.3. 요소 유형별 전용 서식

**텍스트 / Excel 필드:**
- *Excel 열 매핑* (Excel 필드에만 해당): 해당하는 Excel 열을 선택하고 접두사/접미사를 추가합니다 (예: "상품코드: " + 값 + " 원").
- 고정 내용, 글자 크기, 글자 굵기(보통/굵게), 내용 정렬(왼쪽/가운데/오른쪽).

**바코드:**
- 바코드 종류(CODE128, EAN13 등), 바코드 아래 숫자 표시 켜기/끄기, 텍스트 간격, 글자 크기, 글자 굵기.
- Excel 열에 매핑하여 각 라벨이 데이터에 따라 서로 다른 바코드를 인쇄하도록 할 수 있습니다.

**QR 코드:**
- 바코드와 유사합니다: 아래 텍스트 표시 켜기/끄기, 텍스트 간격, Excel 열 매핑 가능.

**이미지 삽입:**
- 컨테이너 크기를 조정해도 이미지는 원본 비율을 자동으로 유지하며 늘어나거나 왜곡되지 않습니다.

## 6. EXCEL 데이터 가져오기 및 열 매핑

### 6.1. 데이터 파일 가져오기
도구모음의 녹색 **"데이터 가져오기 (.xls, .xlsx, .csv)"** 버튼을 클릭하고, 데이터 목록이 포함된 Excel/CSV 파일을 선택하세요(각 행은 라벨 하나, 각 열은 정보 유형 하나에 해당합니다. 예: 이름, 직책, 부서 등).

가져오기가 완료되면 왼쪽 패널의 **"Excel 데이터 열"** 영역에 열 이름 목록과 읽어들인 데이터 행 수가 표시됩니다.

### 6.2. 요소에 열 매핑하기
두 가지 방법이 있습니다:
1. **빠른 방법:** 캔버스에서 아무 요소도 선택하지 않은 상태에서 왼쪽 패널의 열 이름을 직접 클릭하면 → 앱이 자동으로 해당 열에 매핑된 새 "Excel 필드" 요소를 생성합니다.
2. **정확한 방법:** 캔버스에서 기존 요소(텍스트/Excel 필드/바코드/QR 코드)를 선택하면 → 오른쪽 패널에 **"Excel 열 매핑"** 상자(노란색 배경)가 표시됩니다 → 왼쪽 패널의 열 이름을 클릭하여 현재 선택된 요소에 매핑하거나, "해당하는 Excel 열을 선택하세요" 드롭다운에서 직접 선택합니다.

### 6.3. Excel 데이터 지우기
가져오기 버튼 옆의 작은 휴지통 아이콘을 클릭하면 가져온 모든 Excel 데이터를 지울 수 있습니다(라벨 디자인에는 영향을 주지 않습니다).

> 💡 **참고:** 어떤 요소도 Excel 열에 매핑되어 있지 않다면, 데이터를 가져왔더라도 앱은 "인쇄 매수"에 입력된 수만큼만 인쇄합니다(데이터 행 수만큼 곱하지 않음). 모든 라벨의 내용이 동일할 것이기 때문입니다.

## 7. 미리보기 및 인쇄 범위

이 두 영역은 **Excel 데이터를 가져왔고 해당 데이터에 매핑된 요소가 하나 이상 있을 때만** 표시됩니다.

- **미리보기:** 왼쪽/오른쪽 화살표 버튼을 사용하여 각 데이터 행을 탐색하고, 해당 라벨이 어떻게 인쇄될지 미리 볼 수 있습니다.
- **인쇄 범위:**
  - *전체:* 모든 데이터 행을 인쇄합니다.
  - *첫 페이지 (1행):* 첫 번째 데이터 행만 인쇄합니다.
  - *사용자 지정:* 인쇄할 "시작 행... 끝 행..." 범위를 직접 입력합니다.

## 8. 템플릿 저장 및 열기

- **템플릿 저장:** 보라색 **"템플릿 저장"** 버튼을 클릭하여 현재 전체 디자인(모든 요소의 위치, 크기, 서식, 용지 크기 설정 등)을 컴퓨터에 `.json` 파일로 저장합니다. 완성된 라벨 디자인을 보관하거나, 다른 사람과 공유하거나, 나중에 다시 사용할 때 활용하세요.
- **템플릿 열기:** 어두운 색 **"템플릿 열기"** 버튼을 클릭하고 이전에 저장한 `.json` 파일을 선택하면 동일한 디자인을 그대로 불러올 수 있습니다.

> 참고: 템플릿 파일에는 **가져온 Excel 데이터가 저장되지 않습니다** — 템플릿을 연 후 디자인에 데이터 매핑이 사용되었다면 Excel 파일을 다시 가져와야 합니다.

## 9. 라벨 인쇄 및 PDF 내보내기

### 9.1. 직접 인쇄
1. **"인쇄 설정"** 영역(라벨 크기, 격자 행 x 열)이 프린터에 실제로 장착된 용지 롤/시트와 일치하는지 꼼꼼히 확인하세요.
2. **"인쇄 매수"**를 입력하세요(Excel 데이터를 사용하지 않는 경우 인쇄할 라벨 수, 매핑을 사용하는 경우 각 데이터 행당 인쇄할 매수).
3. 인쇄 버튼 옆의 드롭다운에서 올바른 **프린터**를 선택하세요(앱이 컴퓨터에 설치된 프린터 목록을 자동으로 표시합니다).
4. 파란색 **"라벨 인쇄"** 버튼을 클릭하세요.

### 9.2. PDF 내보내기
직접 인쇄 시 용지 크기가 잘못되거나 위치가 어긋나는 경우(보통 프린터 드라이버 문제로 발생), 녹색 **"PDF 내보내기"** 버튼을 사용하세요 — 앱이 디자인한 크기와 **정확히 일치**하는 PDF 파일을 생성합니다. 해당 파일을 Adobe Reader / Foxit Reader로 열어 인쇄할 때, 반드시 **"실제 크기 / 100%"** 인쇄 옵션을 선택하고 "페이지에 맞추기"는 선택하지 마세요.

## 10. 자주 발생하는 문제 해결

| 문제 | 원인 및 해결 방법 |
|---|---|
| 인쇄 위치가 어긋나거나 한 줄당 라벨 수가 맞지 않음 | "격자 (행 x 열)"의 **열** 값이 실제 용지의 한 줄당 라벨 수와 정확히 일치하는지 확인하세요 |
| 인쇄 매수를 1보다 크게 설정해도 라벨이 1장만 인쇄됨 | 올바른 프린터가 선택되었는지 확인하세요. **PDF 내보내기** 후 Adobe/Foxit Reader로 수동 인쇄(실제 크기 100%)를 시도해 보세요 |
