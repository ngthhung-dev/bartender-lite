## 1. 概要

**Bartender Lite** は、パソコン上で直接ラベル（バーコード、QRコード、商品情報など）をデザイン・印刷できる無料アプリケーションです。Excel ファイルからのデータ一括取込みに対応しており、TSC シリーズなどの専用ラベルプリンターや、その他あらゆるプリンターに直接印刷できます。

**主な機能：**
- テキスト、Excel データフィールド、バーコード、QRコード、図形、画像を自由に配置してラベルをデザインできます。
- ラベルサイズと行・列数に応じて、合計用紙サイズを自動計算します。
- Excel データに基づく一括印刷（差し込み印刷）に対応しています。
- 直接印刷、またはデザイン通りのサイズで PDF に出力できます。
- 多言語インターフェース対応：ベトナム語、英語、簡体字中国語、韓国語、日本語。

## 2. 画面構成の概要

アプリの画面は主に 4 つのエリアで構成されています：

| エリア | 位置 | 機能 |
|---|---|---|
| **上部ツールバー** | 画面上部 | ロゴ、言語選択、テンプレートの開く/保存、Excel データ取込み、プレビュー、印刷範囲、印刷部数、プリンター選択、印刷、PDF出力、すべて削除 |
| **左パネル** | 画面左側 | デザイン要素の追加、取り込んだ Excel の列一覧、印刷設定（ラベルサイズ、グリッド、用紙サイズ） |
| **デザインキャンバス** | 画面中央 | ラベル上に要素をドラッグ＆ドロップして配置するエリア |
| **右パネル** | 画面右側 | 選択中の要素の詳細プロパティ（サイズ、位置、書式など） |

キャンバスの両側にある小さな青いカプセル型ボタンは、左右のパネルを**表示/非表示**にするためのもので、必要に応じて作業スペースを広げられます。

キャンバスの右下には、キャンバスを拡大・縮小する**ズーム**ツールバーと、画面に自動的に合わせる「全体表示」ボタンがあります。

## 3. インターフェース言語の変更

左上のロゴとアプリ名の横に言語選択ボックスがあります。クリックして以下から選択してください：

- 🇻🇳 Tiếng Việt（ベトナム語、デフォルト）
- en English（英語）
- 🇨🇳 简体中文（簡体字中国語）
- 🇰🇷 한국어（韓国語）
- 🇯🇵 日本語

画面全体（ボタン、ラベル、メッセージ）が即座に切り替わります。選択した言語は次回アプリを開いたときに**自動的に記憶**されるため、再度選択する必要はありません。

## 4. ラベルサイズと用紙サイズの設定

左パネル下部の**「印刷設定」**エリアにあります：

### 4.1. 単位
作業単位を選択します：**ミリメートル (mm)**、**インチ (in)**、または **ピクセル (px)**。

### 4.2. プリセットサイズ
よく使われるラベルサイズ（35x22mm、70x100mm、80x40mm、100x50mm、100x75mm）をすばやく選択するか、**「カスタム」**を選択して独自のサイズを入力できます。

### 4.3. 幅 x 高さ（ラベル1枚）
**ラベル1枚**のサイズを入力します — これが画面中央のデザインキャンバスの実際のサイズになります。

### 4.4. グリッド（行 x 列）
- **行**：1枚の印刷ページに縦に並ぶラベルの数です。
- **列**：1枚の印刷ページに横に並ぶラベルの数です（つまり、お使いのロール紙・シートの1行に並ぶラベルの数）。

> ⚠️ **重要：** ラベル用紙が1行に3枚並んでいる場合は、**列 = 3** と入力してください。列数を誤って入力すると、ラベルが用紙上の誤った位置に印刷されます。

### 4.5. 合計用紙サイズ（幅 x 高さ）
この項目は（ラベル幅 × 列数）×（ラベル高さ × 行数）で**自動的に計算**され、手動で入力・編集することはできません。これが、印刷または PDF 出力時に実際に使用される用紙サイズです。

**例：** 35x22mm のラベルが1行に3枚並ぶロール紙の場合 → 列 = 3、行 = 1 と入力 → 合計用紙サイズは自動的に 105 x 22mm と計算されます。

## 5. デザイン要素の追加と編集

**「要素を追加」**エリア（左パネル上部）で、追加したい要素の種類をクリックします：

| 要素 | 説明 |
|---|---|
| 🔤 **テキスト** | ご自身で入力する固定内容の自由なテキスト |
| 🗄️ **Excel フィールド** | 取り込んだ Excel ファイルの特定の列から内容を自動的に取得するテキストボックス |
| \|\|\|\| **バーコード** | さまざまな規格に対応したバーコード |
| ▦ **QRコード** | QRコード |
| ▢ **図形** | 装飾用の長方形・枠線 |
| 🖼️ **画像を挿入** | ロゴや PNG、JPG、SVG 画像を挿入 |

### 5.1. キャンバス上での要素の操作
- **移動：** マウスでドラッグするか、要素を選択した状態で矢印キー（↑↓←→）を使用します。**Shift** キー + 矢印キーで、より速く移動できます（10px 単位）。
- **サイズ変更：** 選択中の要素の四隅・四辺にある小さな青い四角形をドラッグします。
- **回転：** 要素の上にある青い点をドラッグするか、右パネルの「回転 (°)」／「カスタム角度」欄を使用します。
- **複製：** 要素を選択した状態で **Ctrl+C** を押してから **Ctrl+V** を押すか、右パネルの「複製」ボタンをクリックします。
- **要素を1つ削除：** 要素を選択した状態で右パネルの「この要素を削除」ボタンをクリックするか、**Delete** キーを押します。
- **デザイン全体を削除：** ツールバーの赤い**「すべて削除」**ボタンをクリックします。

> 💡 要素は常にデザインエリア（ラベルの範囲）の外にドラッグ・移動できないよう制限されています。

### 5.2. 共通プロパティ（右パネル）
要素を選択すると、右パネルに以下が表示されます：
- **ページに合わせて配置：** ラベルを基準に左揃え／中央揃え／右揃え、上揃え／中央揃え／下揃え。
- **サイズと位置 (px)：** 幅、高さ、X 座標、Y 座標、回転角度。

### 5.3. 要素タイプ別の書式設定

**テキスト／Excel フィールド：**
- *Excel 列マッピング*（Excel フィールドのみ）：対応する Excel 列を選択し、接頭辞／接尾辞を追加します（例：「品番：」＋値＋「円」）。
- 固定内容、文字サイズ、文字の太さ（標準／太字）、テキストの配置（左／中央／右）。

**バーコード：**
- バーコードの種類（CODE128、EAN13 など）、バーコード下の数字表示の切り替え、テキストの間隔、文字サイズ、文字の太さ。
- Excel 列にマッピングすることで、データに応じて各ラベルに異なるバーコードを印刷できます。

**QRコード：**
- バーコードと同様：下にテキストを表示する切り替え、テキストの間隔、Excel 列へのマッピングが可能です。

**画像を挿入：**
- コンテナのサイズを変更しても、画像は自動的に元の縦横比を保ち、伸縮や歪みが発生しません。

## 6. EXCEL データの取込みと列マッピング

### 6.1. データファイルの取込み
ツールバーの緑色の**「データ取込み (.xls, .xlsx, .csv)」**ボタンをクリックし、データ一覧が含まれる Excel/CSV ファイルを選択します（各行が1枚のラベルに対応し、各列が1種類の情報に対応します。例：氏名、役職、部署など）。

取込みが成功すると、左パネルの**「Excel データ列」**エリアに列名の一覧と、読み込まれたデータの行数が表示されます。

### 6.2. 要素への列のマッピング
方法は2通りあります：
1. **簡単な方法：** キャンバス上でどの要素も選択されていない状態で、左パネルの列名を直接クリックすると → アプリが自動的にその列にマッピングされた新しい「Excel フィールド」要素を作成します。
2. **正確な方法：** キャンバス上の既存の要素（テキスト／Excel フィールド／バーコード／QRコード）を選択すると → 右パネルに**「Excel 列マッピング」**ボックス（黄色の背景）が表示されます → 左パネルの列名をクリックして現在選択中の要素にマッピングするか、「対応する Excel 列を選択してください」のドロップダウンから直接選択します。

### 6.3. Excel データの消去
取込みボタンの横にある小さなゴミ箱アイコンをクリックすると、取り込んだ Excel データをすべて消去できます（ラベルのデザインには影響しません）。

> 💡 **注意：** どの要素も Excel 列にマッピングされていない場合、データを取り込んでいても、アプリは「印刷部数」に入力された数だけ印刷します（データの行数倍にはなりません）。すべてのラベルの内容が同じになるためです。

## 7. プレビューと印刷範囲

これら2つのエリアは、**Excel データを取り込んでおり、かつそのデータにマッピングされた要素が少なくとも1つある場合にのみ**表示されます。

- **プレビュー：** 左右の矢印ボタンを使って各データ行を順に確認し、対応するラベルの印刷イメージをプレビューできます。
- **印刷範囲：**
  - *すべて：* すべてのデータ行を印刷します。
  - *先頭ページ（1行目）：* 最初のデータ行のみを印刷します。
  - *カスタム：* 印刷したい「開始行～終了行」の範囲を直接入力します。

## 8. テンプレートの保存と読み込み

- **テンプレートを保存：** 紫色の**「テンプレートを保存」**ボタンをクリックすると、現在のデザイン全体（すべての要素の位置・サイズ・書式、用紙サイズ設定など）がパソコン上に `.json` ファイルとして保存されます。完成したラベルデザインを保管したり、他の人と共有したり、後で再利用したりする際に使用します。
- **テンプレートを開く：** 濃い色の**「テンプレートを開く」**ボタンをクリックし、以前保存した `.json` ファイルを選択すると、同じデザインをそのまま読み込めます。

> 注意：テンプレートファイルには**取り込んだ Excel データは保存されません** — テンプレートを開いた後、デザインでデータマッピングを使用している場合は Excel ファイルを再度取り込む必要があります。

## 9. ラベル印刷と PDF 出力

### 9.1. 直接印刷する
1. **「印刷設定」**エリア（ラベルサイズ、グリッドの行 x 列）が、プリンターに実際にセットされているロール紙／シートと一致しているか、よく確認してください。
2. **「印刷部数」**を入力します（Excel データを使用しない場合は印刷するラベルの枚数、マッピングを使用する場合は各データ行ごとの印刷部数）。
3. 印刷ボタンの横にあるドロップダウンから正しい**プリンター**を選択します（アプリがパソコンにインストールされているプリンターを自動的に一覧表示します）。
4. 青色の**「ラベル印刷」**ボタンをクリックします。

### 9.2. PDF を出力する
直接印刷で用紙サイズが正しくない、または位置がずれる場合（通常はプリンタードライバーが原因）は、緑色の**「PDF 出力」**ボタンを使用してください — アプリがデザイン通りの**正確な**サイズで PDF ファイルを生成します。そのファイルを Adobe Reader／Foxit Reader で開いて印刷する際は、必ず**「実際のサイズ／100%」**の印刷オプションを選択し、「ページに合わせる」は選択しないでください。

## 10. よくあるトラブルの対処法

| トラブル | 原因と対処法 |
|---|---|
| 印刷位置がずれる、または1行あたりのラベル数が合わない | 「グリッド（行 x 列）」の**列**の値が、実際の用紙の1行あたりのラベル数と完全に一致しているか確認してください |
| 印刷部数を1より大きく設定しても、ラベルが1枚しか印刷されない | 正しいプリンターが選択されているか確認してください。**PDF 出力**を行い、Adobe／Foxit Reader で手動印刷（実際のサイズ100%）を試してください |
| 選択したプリンターではなく、既定のプリンターに印刷されてしまう | 最新バージョンに更新してください — ドロップダウンでプリンターを選択すると自動的に切り替わるようになりました |
| 印刷または PDF 出力時にベトナム語の声調記号が欠けたり途切れたりする | 直近のアップデートで修正済みです — 最新バージョンをご利用ください |
| Excel を取り込んだのに「プレビュー」／「印刷範囲」が表示されない | この2つのエリアが表示されるには、Excel 列に**マッピングされた要素**が少なくとも1つ必要です |
| 印刷した QRコード／バーコードがぼやける | 右パネルで QRコード／バーコード要素の幅・高さを大きくしてください |
