## 1. 软件简介

**Bartender Lite** 是一款免费应用程序，可让您直接在电脑上自行设计并打印标签（条形码、二维码、产品信息等），支持从 Excel 文件批量导入数据，并可直接连接专用标签打印机（如 TSC 系列）或其他任意打印机进行打印。

**主要功能：**
- 自由设计标签：可添加文本、Excel 数据字段、条形码、二维码、形状和图片。
- 根据标签尺寸和行/列数量自动计算总纸张尺寸。
- 根据 Excel 数据批量打印（邮件合并）。
- 直接打印或导出与设计尺寸完全一致的 PDF 文件。
- 多语言界面：越南语、英语、简体中文、韩语、日语。

## 2. 界面概览

应用界面分为 4 个主要区域：

| 区域 | 位置 | 功能 |
|---|---|---|
| **顶部工具栏** | 窗口顶部 | 徽标、语言选择器、打开/保存模板、导入 Excel 数据、预览、打印范围、打印份数、选择打印机、打印、导出 PDF、清空全部 |
| **左侧面板** | 左侧 | 添加设计元素、已导入的 Excel 列列表、打印设置（标签尺寸、网格、纸张尺寸） |
| **设计画布** | 中间 | 用于拖放和排列标签上各元素的区域 |
| **右侧面板** | 右侧 | 当前选中元素的详细属性（尺寸、位置、格式等） |

画布两侧各有一个小型蓝色胶囊状按钮，用于**显示/隐藏**左右面板，需要时可获得更多操作空间。

画布右下角有**缩放**工具栏，可放大/缩小画布，以及"适应"按钮可自动将画布调整为适合屏幕大小。

## 3. 切换界面语言

在左上角徽标和应用名称旁边有一个语言选择框，点击后可选择：

- 🇻🇳 Tiếng Việt（越南语，默认）
- en English（英语）
- 🇨🇳 简体中文
- 🇰🇷 한국어（韩语）
- 🇯🇵 日本語（日语）

整个界面（按钮、标签、提示信息）将立即切换。您选择的语言会在下次打开应用时**自动记住**，无需重新选择。

## 4. 设置标签尺寸与纸张尺寸

位于左侧面板底部的**"打印设置"**区域：

### 4.1. 度量单位
选择工作单位：**毫米 (mm)**、**英寸 (in)** 或 **像素 (px)**。

### 4.2. 预设模板
快速选择常见的标签尺寸（35x22mm、70x100mm、80x40mm、100x50mm、100x75mm），或选择**"自定义"**以自行输入尺寸。

### 4.3. 宽 x 高（单个标签）
输入**单个标签**的尺寸——这就是屏幕中央设计画布的实际尺寸。

### 4.4. 网格（行 x 列）
- **行**：一页打印纸上纵向排列的标签数量。
- **列**：一页打印纸上横向排列的标签数量（即您所用纸卷/纸张一行中排列的标签数量）。

> ⚠️ **重要提示：** 如果您的标签纸卷每行有 3 个标签，请输入**列 = 3**。若列数输入错误，标签将打印到纸张上错误的位置。

### 4.5. 总纸张尺寸（宽 x 高）
此字段为**自动计算**结果 = （单个标签宽度 × 列数）×（单个标签高度 × 行数），无需也无法手动编辑。这就是打印或导出 PDF 时实际使用的纸张尺寸。

**示例：** 标签尺寸为 35x22mm，纸卷每行有 3 个标签 → 输入列 = 3，行 = 1 → 总纸张尺寸将自动计算为 105 x 22mm。

## 5. 添加与编辑设计元素

在**"添加元素"**区域（左侧面板顶部），点击想要添加的元素类型：

| 元素 | 说明 |
|---|---|
| 🔤 **文本** | 自定义文字，内容由您自行输入并固定 |
| 🗄️ **Excel 字段** | 内容自动从已导入的 Excel 文件某一列中读取的文本框 |
| \|\|\|\| **条形码** | 支持多种标准的条形码 |
| ▦ **二维码** | QR 二维码 |
| ▢ **形状** | 装饰性的矩形/边框 |
| 🖼️ **插入图片** | 插入徽标或 PNG、JPG、SVG 格式图片 |

### 5.1. 在画布上操作元素
- **移动：** 用鼠标拖动，或在选中元素后使用方向键（↑↓←→）。按住 **Shift** + 方向键可加快移动速度（每次移动 10 像素）。
- **调整大小：** 拖动所选元素四角/四边上的蓝色小方块。
- **旋转：** 拖动元素上方的蓝色圆点，或在右侧面板中使用"旋转 (°)"/"自定义角度"输入框。
- **复制：** 选中元素后按 **Ctrl+C** 再按 **Ctrl+V**，或点击右侧面板中的"复制"按钮。
- **删除单个元素：** 选中后点击右侧面板中的"删除此元素"按钮，或按 **Delete** 键。
- **清空整个设计：** 点击工具栏上的红色**"清空全部"**按钮。

> 💡 元素始终被限制在设计区域（标签边界）内，无法被拖出该区域。

### 5.2. 通用属性（右侧面板）
选中元素后，右侧面板将显示：
- **与页面对齐：** 相对于标签进行左/中/右对齐、上/中/下对齐。
- **尺寸和位置 (px)：** 宽度、高度、X 坐标、Y 坐标、旋转角度。

### 5.3. 各类型元素的专属格式

**文本 / Excel 字段：**
- *Excel 列映射*（仅 Excel 字段有）：选择对应的 Excel 列，添加前缀/后缀（例如："货号："+ 数值 +"元"）。
- 固定内容、字号、字体粗细（常规/粗体）、内容对齐方式（左/中/右）。

**条形码：**
- 条形码类型（CODE128、EAN13 等）、开关条形码下方数字显示、文字间距、字号、字体粗细。
- 可映射 Excel 列，使每张标签根据数据打印不同的条形码。

**二维码：**
- 与条形码类似：开关下方文字显示、文字间距，可映射 Excel 列。

**插入图片：**
- 调整容器大小时，图片会自动保持原始宽高比，不会出现拉伸或变形。

## 6. 导入 EXCEL 数据与列映射

### 6.1. 导入数据文件
点击工具栏上的绿色**"导入数据 (.xls, .xlsx, .csv)"**按钮，选择包含数据列表的 Excel/CSV 文件（每一行对应一张标签，每一列对应一种信息类型，例如：姓名、职位、部门等）。

导入成功后，左侧面板的**"Excel 数据列"**区域将显示各列的名称，以及读取到的数据行数。

### 6.2. 将数据列映射到元素
有两种方式：
1. **快捷方式：** 画布上未选中任何元素时，直接点击左侧面板中的列名 → 应用将自动创建一个新的"Excel 字段"元素并映射到该列。
2. **精确方式：** 在画布上选中一个已有元素（文本/Excel 字段/条形码/二维码）→ 右侧面板将显示**"Excel 列映射"**框（黄色背景）→ 点击左侧面板中的列名将其映射到当前选中元素，或直接在"选择对应的 Excel 列"下拉菜单中选择。

### 6.3. 清除 Excel 数据
点击导入按钮旁边的小垃圾桶图标，即可清除所有已导入的 Excel 数据（不会影响标签设计）。

> 💡 **提示：** 如果没有任何元素映射到 Excel 列，即使已导入数据，应用仍将只按"打印份数"中输入的数量打印（不会乘以数据行数），因为每张标签的内容将完全相同。

## 7. 预览与打印范围

只有在您**已导入 Excel 数据且至少有一个元素已映射**到该数据时，这两个区域才会显示。

- **预览：** 使用左右箭头按钮浏览各数据行，预览对应标签的实际打印效果。
- **打印范围：**
  - *全部：* 打印所有数据行。
  - *第一页（第 1 行）：* 仅打印第一条数据。
  - *自定义：* 自行输入"从第...行 到第...行"的打印范围。

## 8. 保存与打开模板

- **保存模板：** 点击紫色**"保存模板"**按钮，将当前的整个设计（所有元素的位置、尺寸、格式，以及纸张尺寸设置等）保存为电脑上的 `.json` 文件。可用于保留已完成的标签设计、分享给他人或以后重复使用。
- **打开模板：** 点击深色**"打开模板"**按钮，选择之前保存的 `.json` 文件，即可完全恢复该设计。

> 注意：模板文件**不会保存已导入的 Excel 数据**——打开模板后，如果设计中使用了数据映射，您需要重新导入 Excel 文件。

## 9. 打印标签与导出 PDF

### 9.1. 直接打印
1. 仔细检查**"打印设置"**区域（标签尺寸、网格行 x 列）是否与打印机中实际装入的纸卷/纸张一致。
2. 输入**"打印份数"**（若不使用 Excel 数据，则为要打印的标签数量；若使用了映射，则为每条数据打印的份数）。
3. 在"打印"按钮旁的下拉菜单中选择正确的**打印机**（应用会自动列出电脑上已安装的打印机）。
4. 点击蓝色**"打印标签"**按钮。

### 9.2. 导出 PDF
如果直接打印出现纸张尺寸错误或位置偏移（通常由打印机驱动程序引起），请使用绿色**"导出 PDF"**按钮——应用将生成一个与设计尺寸**完全一致**的 PDF 文件。用 Adobe Reader / Foxit Reader 打开该文件进行打印，务必选择**"实际大小 / 100%"**打印模式，不要选择"适应页面"。

## 10. 常见问题排查

| 问题 | 原因与解决方法 |
|---|---|
| 打印出的标签位置错位，或每行标签数量不对 | 检查"网格（行 x 列）"中的**列数**是否与实际纸张每行的标签数量完全一致 |
| 即使打印份数设置大于 1，也只打印出 1 张标签 | 检查所选打印机是否正确；可尝试**导出 PDF** 后通过 Adobe/Foxit Reader 手动打印（实际大小 100%） |
| 应用打印到默认打印机而非所选打印机 | 请更新至最新版本——应用现已支持在您选择打印机后自动切换 |
| 打印或导出 PDF 时越南语声调符号显示不完整/被截断 | 最近的更新已修复此问题——请确保使用最新版本 |
| 已导入 Excel 但未显示"预览"/"打印范围" | 需要至少有一个元素**映射**到 Excel 列，这两个区域才会显示 |
| 打印出的二维码/条形码模糊不清 | 在右侧面板中增大二维码/条形码元素的宽度/高度 |
